Case Study · Web & Games

Math Dash

Problem

Static question banks quickly become predictable, and random multiple-choice distractors rarely reflect how learners actually slip on signs, order of operations, or conditional probability.

Approach

I built procedural problem generators covering Arithmetic, Linear Algebra, Number Theory, Descriptive Statistics, and Probability across selectable difficulty levels, paired with rule-based distractor generation modelled on common mistakes. The game separates game logic from the DOM and supports Sprint and Survival modes, high-resolution timers, speed bonuses, combo multipliers, synthesized Web Audio API feedback, canvas confetti, and full keyboard controls.

Result

At the end of each run, a response-time statistics panel computes accuracy alongside the mean, median, and standard deviation (σ) of response times, storing personal bests locally in the browser with zero external libraries.

What I learned

Separating pure question-generation and timing statistics modules from DOM rendering and Web Audio synthesis kept the ES module architecture straightforward to test and debug.

Case Study · Data & Python

Student Marks Analyzer

Dataset note: All analyses and outputs use a synthetic dataset of 120 generated student records created specifically to test edge cases without exposing real student data.

Problem

Raw examination marksheets frequently arrive with duplicate rows, missing entries, and out-of-range scores that skew averages and hide students who need early academic support.

Approach

I developed a Python CLI pipeline using pandas, NumPy, and matplotlib to validate raw CSV files, handle duplicates and out-of-range scores, and apply median imputation alongside a data-cleaning summary report. It computes 12 univariate metrics, Pearson correlation, OLS regression via np.polyfit with R², outlier detection using both IQR and z-scores, and at-risk student flags.

Result

A single CLI execution generates 9 diagnostic charts, compiles a multi-page PDF report alongside a Markdown summary, and passes an automated pytest suite covering cleaning rules and statistical calculations.

What I learned

Comparing IQR and z-score outlier detection on skewed synthetic distributions showed how sensitive parametric thresholds are to uncleaned extreme values.

Case Study · Web & Data

Expense Tracker & Visual Budget App

Data note: Includes seeded demo data so reviewers can inspect populated category breakdowns and monthly cash-flow trends immediately in the browser.

Problem

Tracking day-to-day spending across multiple categories without overshooting monthly budgets is difficult when expense logs sit in raw lists without visual summaries or limit warnings.

Approach

I built a client-side personal expense tracking web application featuring transaction logging, category filtering, budget limit alerts, and persistent browser storage via localStorage, paired with visual spending breakdowns summarizing category-wise expenses and monthly cash-flow trends.

Result

The application runs directly on GitHub Pages with zero build step or third-party runtime dependencies, letting users inspect seeded demo budgets or log and filter their own expenses in light or dark themes.

What I learned

Structuring state updates cleanly around localStorage serialization and hand-coded SVG charts kept category filtering, budget alerts, and trend summaries responsive without external charting libraries.
